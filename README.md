# cifarMask
# [WIP]
Downloads and processes images from MS-COCO and Oxford-IIIT Pet datasets to create CIFAR-10 formatted datasets with an extra channel of bytes in addition to RGB to denote segmentation masks. The program seems functional and is currently being tested, but the project is still a work in progress! I will add further documentation and clean up the scripts once I've verified that everything works as expected.

For use, you must download COCO annotations and put them into a folder named coco in the same directory as the dataloader script
